# Country reference source

`geonames-countryInfo.txt` is the GeoNames country information export downloaded
from <https://download.geonames.org/export/dump/countryInfo.txt>.

GeoNames data is licensed under the Creative Commons Attribution 4.0 License:
<https://creativecommons.org/licenses/by/4.0/>. The source is retained so the
generated seed is auditable and repeatable. Historical `AN` and `CS` rows are
excluded; the temporary `XK` code remains selectable as a politically neutral
reference choice outside the 195-country statistics denominator.
